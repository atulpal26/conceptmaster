# ConceptMaster.org

A free, static website designed for GitHub Pages.

## Structure

- `index.html` — homepage
- `css/style.css` — styling
- `js/script.js` — offer form and configuration
- `resources/` — resource-category pages
- `assets/` — favicon and future images

## Before publishing

Open `js/script.js` and replace:

`YOUR_EMAIL@example.com`

with the email address where you want domain inquiries.

Also update the contact email in `index.html`.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload the project files.
3. Go to Settings → Pages.
4. Select `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save.
7. Add `conceptmaster.org` under Custom domain.
8. Configure the DNS records at your domain registrar as instructed by GitHub.

## Content and copyright

Only publish material that you created yourself or have permission to redistribute. In particular, do not upload scans/photos/PDFs of copyrighted coaching material unless you have the necessary rights.
